# Antigravity Migration Guide

To perfectly clone this project, its history, the AI's memory, and your IDE layout to a new laptop, copy these 3 directories:

### 1. The Codebase & Builds
**Path:** `C:\Users\eqbir\CodeProjects\Antigravity`
*   Contains all source code, `build.gradle.kts`, `App.Outputs` (APKs), and the `build.log\caveman.log` ledger.

### 2. The AI Brain & Knowledge
**Path:** `C:\Users\eqbir\.gemini\antigravity`
*   Contains the AI's state, conversation history (`\brain`), and global project rules (`\knowledge`).

### 3. Antigravity IDE Settings
**Path:** `C:\Users\eqbir\AppData\Roaming\Antigravity\User`
*   Contains `settings.json` (your model selections, themes), custom `snippets`, and local IDE workspace data.

**Tip:** Compress each of these folders into `.zip` files for easy transfer, and extract them into the exact same file paths on the new machine.
